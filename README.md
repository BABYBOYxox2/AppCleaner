# AppCleaner

เครื่องมือล้างข้อมูลสำหรับ Windows พร้อมหน้าต่าง WPF และภาพเคลื่อนไหว ใช้งานผ่าน Windows PowerShell 5.1 ได้โดยไม่ต้องติดตั้งหรือแตกไฟล์โปรแกรม

## เปิดใช้งาน

เปิด **Windows PowerShell** แล้ววางคำสั่งนี้:

```powershell
irm https://raw.githubusercontent.com/BABYBOYxox2/AppCleaner/main/run.ps1 | iex
```

คำสั่งนี้โหลดและรัน `run.ps1` จาก repository นี้โดยตรง หน้าต่างจะเปิดให้เลือกและตรวจรายการก่อนยืนยันการลบ การเปิดหน้าต่างเพียงอย่างเดียวไม่ลบข้อมูล

ปุ่ม **ล้างทั้งหมด** ด้านบนจะถอนและล้างข้อมูลของแอปที่ติ๊กไว้ พร้อมล้างไฟล์ใน Downloads รูปใน Pictures และไฟล์ขยะใน Temp ในขั้นตอนเดียว ถ้าติ๊ก Google Chrome, LINE, Telegram และ Discord ครบ ก็จะทำทั้ง 4 แอป หากไม่ติ๊กแอปเลยจะทำเฉพาะ Downloads, Pictures และ Temp กดเพื่อสแกน ตรวจชื่อแอปและรายการทั้งหมดในหน้าต่างยืนยัน แล้วกด **Confirm all cleanup** เพื่อเริ่ม หากกด Cancel จะไม่มีการลบ

งานจะทำต่อทีละส่วนและสรุปรายการที่สำเร็จ ข้าม หรือผิดพลาดไว้ใน Activity log หากถอนแอปหนึ่งไม่สำเร็จ จะเก็บข้อมูลของแอปนั้นไว้และทำงานส่วนอื่นต่อ ปุ่ม Quick clean และปุ่มแยกยังใช้ทำเฉพาะงานได้ตามเดิม

เมื่อ **ล้างทั้งหมดเสร็จ** หน้าต่าง AppCleaner จะปิดเอง หากมีข้อผิดพลาดหรือไฟล์ที่ข้าม จะเปิดค้างไว้ให้ตรวจ Activity log แอปที่ไม่มีอยู่แล้วและโฟลเดอร์ว่างไม่ขัดขวางการปิดอัตโนมัติ โหมด Preview และปุ่มทำงานแยกยังคงเปิดหน้าต่างไว้ การปิดนี้ไม่ปิดหน้าต่าง PowerShell ที่ใช้เปิดโปรแกรม

แก้กรณี Chrome ขึ้น `Cannot delete a subkey tree because the subkey does not exist`: ลบคีย์ Registry ที่อยู่ในรายการอนุญาตผ่าน [Registry API](https://learn.microsoft.com/en-us/dotnet/api/microsoft.win32.registrykey.deletesubkeytree?view=netframework-4.8.1) โดยถือว่าคีย์ที่ไม่มีอยู่แล้วเสร็จเรียบร้อย และตรวจว่าคีย์หายไปจริงหลังลบ หากสิทธิ์ไม่พอหรือยังมีคีย์เหลือ จะยังรายงานข้อผิดพลาดพร้อมตำแหน่งคีย์

แก้กรณี Discord ขึ้น `Cannot verify process location`: โปรแกรมจะอ่านตำแหน่งผ่าน Windows API เมื่อวิธีปกติอ่านไม่ได้ ปิดเฉพาะโปรเซสที่ตรวจตำแหน่งได้ แล้วรอให้โปรเซสลูกปิดตามก่อนถอนและล้างข้อมูล หากยังถูกปฏิเสธสิทธิ์ จะหยุดและแสดง PID พร้อมสาเหตุใน Activity log ให้ปิด Discord จากถาดระบบแล้วลองใหม่ หรือเปิด Windows PowerShell แบบ Run as administrator หากยังขึ้น Access is denied

หากใช้ PowerShell 7 ให้เปิด Windows PowerShell ก่อนด้วย `powershell.exe -NoProfile -STA` แล้วจึงวางคำสั่งข้างต้น

## การทำงาน

- ถอน Google Chrome, LINE, Telegram และ Discord พร้อมล้างข้อมูลตามตัวเลือก
- Discord รองรับรุ่นปกติบน Windows ใช้ตัวถอนการติดตั้งที่ลงทะเบียนไว้ แล้วล้าง `%LocalAppData%\Discord` และ `%AppData%\discord` ซึ่งเป็น [ตำแหน่งที่ Discord ระบุ](https://support.discord.com/hc/en-us/articles/115004307527--Windows-Corrupt-Installation) รวมแคชและการตั้งค่าในเครื่อง ไม่รวม Discord PTB หรือ Canary
- ล้างไฟล์และโฟลเดอร์ย่อยที่ตรวจแล้วใน Downloads โดยเก็บโฟลเดอร์ Downloads ไว้
- ลบรูปภาพตามนามสกุลที่รองรับใน Pictures รวมโฟลเดอร์ย่อย โดยเก็บไฟล์ชนิดอื่นและโฟลเดอร์ไว้
- ต้องสแกน ตรวจรายการ และยืนยันก่อนลบถาวร ไม่ผ่านถังขยะ
- ข้ามลิงก์ ไฟล์ที่เปลี่ยนหลังสแกน และรายการที่เข้าถึงไม่ได้ พร้อมรายงานผล

รุ่นนี้ไม่มีโฟลเดอร์โปรแกรมให้ต้องลบตัวเอง บันทึกกิจกรรมของ AppCleaner แสดงในหน้าต่างเท่านั้น Windows, PowerShell และตัวถอนการติดตั้งแอปยังอาจเก็บบันทึกตามปกติ

ไฟล์ AppCleaner รุ่นเก่าที่อยู่ใน Downloads อาจรวมอยู่ในรายการลบที่คุณยืนยันด้วย การลบภายในโฟลเดอร์ที่ซิงก์อาจส่งผลต่อไฟล์บนคลาวด์และอุปกรณ์อื่น

## ตรวจดูหน้าตาโดยไม่ลบข้อมูล

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/BABYBOYxox2/AppCleaner/main/run.ps1))) -Preview
```

โหมด Preview จำลองการทำงาน ไม่มีการถอนแอปหรือลบไฟล์ของผู้ใช้


ล้างไฟล์ขยะ (Junk files)
- หน้า Folder cleanup มีปุ่ม Scan junk files และปุ่มล้างทั้งหมดรวมงานนี้ให้ด้วย
- สแกนเฉพาะ Temp ของผู้ใช้ปัจจุบัน: %LocalAppData%\Temp รวมไฟล์ในโฟลเดอร์ย่อย
- เลือกเฉพาะไฟล์ที่ทั้งสร้างและแก้ไขล่าสุดเกิน 7 วัน โดยเก็บไฟล์ใหม่และโฟลเดอร์ทั้งหมดไว้
- แสดงรายการและขนาดรวมก่อนยืนยันลบถาวร ไม่ผ่านถังขยะ
- เก็บไฟล์ที่ใช้งานอยู่ เปลี่ยนหลังสแกน หรือไม่มีสิทธิ์ลบ พร้อมรายงานใน Activity log
- ข้ามลิงก์และโฟลเดอร์โปรแกรมที่กำลังใช้งาน ไม่บังคับปิดโปรแกรมเพื่อล้าง Temp
- ไม่รวม Windows Temp, Prefetch, ถังขยะ หรือโฟลเดอร์แคชอื่นนอก Temp ของผู้ใช้
